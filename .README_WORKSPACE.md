## Workspace Purpose

This is the **parallel interface & design repository** for INFILTRAITOR. It runs on the `feat/design-interface-hud` branch and develops the game's UI layer, menus, and HUD systems while the main engine evolves independently in `main`.

### What Belongs Here ✅
- **UI scripts** — all files under `godot/scripts/ui/`
- **HUD panels & windows** — reactive components that display game state
- **Input wiring** — InputController, action bindings, menu key handling
- **Menu systems** — Pause Menu, Settings, Level Select (when built)
- **Visual polish** — animations, transitions, theme management, art layering
- **Interface design** — layout, button placement, responsive design

### What Does NOT Belong Here ❌
- **Core logic** — physics, pathfinding, AI, destruction, explosions
- **Game systems** — turn flow, alert meters, damage tracking, prediction
- **Voxel rendering** — wall geometry, baking, lighting calculations
- **Coordinate math** — geometry, slopes, wall heights, storey levels
- **Architecture decisions** — those live in `main` only

```bash
# or from Mac: Serviços → JAMES Qwen Code
```

This automatically:

- Detects PC IP on LAN (via auto-discovery or cache)
- Opens INFILTRAITOR_DESIGN workspace in Qwen Code
- Sets system prompt from `.qwen/system-prompt.md` (Design-Only role)

### 3. Making Changes
- Edit files in `godot/scripts/ui/` and the HUD controllers. ⚠️ There is no
  `godot/scenes/ui/` yet — the HUD is still a CanvasLayer inside
  `godot/scenes/game/room.tscn`, so a new panel either lands there or the
  folder gets created as part of the task that needs it.
- Follow the `PanelBase` / `WindowBase` pattern (see [PROMPTS/PLANNING/INTERFACE_MASTER_PLAN.md](PROMPTS/PLANNING/INTERFACE_MASTER_PLAN.md) § Part 2)
- Wire reactive signals, never write direct game logic
- Use `tr("domain.key")` for player-facing text

Example task: Build PAUSE-MENU-01
```gdscript
# godot/scripts/ui/pause_menu_panel.gd
extends WindowBase

func _ready():
    # Pause the game when this menu opens
    get_tree().paused = true
    
    # Wire buttons to existing signals
    $ResumeButton.pressed.connect(_on_resume_pressed)
    $QuitButton.pressed.connect(_on_quit_pressed)

func _on_resume_pressed():
    close()
    get_tree().paused = false
```

### 4. Verification (Before Committing)
Run these from the design workspace directory:

## Debugging Tips

**"Compile errors when opening design workspace in Godot?"**
- Godot cache was deleted. Copy `.godot/` from main:
  ```bash
  cp -R ../INFILTRAITOR/.godot .
  ```

**"PC connection fails?"**
- Check PC is on and LM Studio is running
- Manually set IP in `.env`: `PC_AUTO_DISCOVER=0`, `LLM_BASE_URL=http://192.168.2.X:1234/v1`

**"Changes lost when switching branches?"**
- This workspace is always on `feat/design-interface-hud`. Never checkout `main` here.
- To pull engine updates: `git merge origin/main` (not checkout)

**"Tests fail but lint passes?"**
- A selftest may be testing engine logic (not UI). That's expected.
- Run only UI-relevant tests: none at the moment, all are engine-scoped.
