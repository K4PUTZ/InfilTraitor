## Workspace Purpose

This is the **authoritative engine repository** for INFILTRAITOR. All core gameplay logic, physics simulation, rendering systems, and architectural decisions live here.

### What Belongs Here ✅
- **Voxel rendering pipeline** — geometry, baking, lighting
- **Physics & destruction** — explosions, detonations, material behavior
- **Movement & pathfinding** — A*, guard navigation, tactical turns
- **Game systems** — prediction/simulation without commits, damage tracking, alerts
- **Architecture & core APIs** — all inviolable rules, coordinate planes, seams

### What Does NOT Belong Here ❌
- **UI/HUD scripts** — see [`/Volumes/Expansion/-----...INFILTRAITOR_DESIGN`](#parallel-design-workspace)
- **Menu systems** — see parallel design workspace
- **Input handling UI** — use the design workspace for button wiring and input UI
- **Visual polish** — animations, transitions, art direction go to design

## Development Workflow

### 1. Starting a Session
```bash
cd /Volumes/Expansion/----- PESSOAL -----/PYTHON/INFILTRAITOR
git status
git pull origin main
```

### 2. Making Changes
- Edit files in `godot/scripts/` (systems, agents, world, controllers, debug)
- **EXCEPTION:** Never modify `godot/scripts/ui/` — that belongs to the design workspace
- Update docs in `docs/` or `PROMPTS/` as needed
- Make small, focused commits with clear `[TAG]` prefixes

### 3. Verification (Before Pushing)
```bash
python3 tools/persistent/project_lint.py          # 0 compile errors
python3 tools/persistent/check_invariants.py      # 0 violations
python3 tools/persistent/gen_codemap.py --check   # codemap in sync
python3 tools/persistent/run_selftests.py         # all 51 tests pass
```

### 4. Committing & Pushing
```bash
git add <files>
git commit -m "[TAG] Brief description of change"
git push origin main
```

**Commit tag conventions:**
- `[FIX]` — bug fixes
- `[FEAT]` — new features (rare; usually a prompt/milestone)
- `[PERF]` — performance improvements
- `[REFACTOR]` — code reorganization (no behavior change)
- `[DOCS]` — documentation updates
- `[PROMPT-ID]` — e.g., `[GLASS-D48]`, `[TARGETING-05]`
