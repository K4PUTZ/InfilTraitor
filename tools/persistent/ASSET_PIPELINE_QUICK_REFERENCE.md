# Asset Pipeline Quick Reference — INFILTRAITOR

Voxel and TileSet generation workflow.

---

## Pipeline Overview

```
Asset Source                  Generator              Output TileSet              In-Game
────────────────────────────────────────────────────────────────────────────────────────
PNG voxel atoms       →  generate_voxel.py     →  tileset_voxels.tres   →  Voxel walls
(source_assets/voxels/)    (32×36 per material)    (32×16 tile_size)

Floor/block/prop PNGs  →  build_tileset.gd     →  tileset_blocks.tres   →  Floor, props
(source_assets/generated/)  (no wall series)        (256×128 tile_size)
```

## Voxel Asset Pipeline (VOXEL series)

**Asset directory:**
```
ASSETS/ISOMETRIC/source_assets/voxels/
├── voxel_concrete.png     ← 32×36 px atom
├── voxel_metal.png        (16 px top face + 20 px side face)
├── voxel_stone.png
└── voxel_wood.png
```

### Voxel Atom Anatomy

```
┌────────────────┐
│   TOP FACE     │   16 px tall (isometric diamond)
│ (32×16 square) │   Base color, flat-lit
├────────────────┤
│   SIDE FACE    │   20 px tall (1.25 × 16)
│  (32×20 rect)  │   Darkened 80%
└────────────────┘
TOTAL: 32×36 px per atom
```

**Generated by `generate_voxel.py`:**
```python
TILE_W  = 32; TILE_H = 16                      # Godot tile_size
SIDE_H  = 20                                    # 1.25 × TILE_H
TOTAL_H = TILE_H + SIDE_H                      # 36 px

TOP  = draw_iso_diamond(TILE_W, TILE_H, base_color)
SIDE = draw_rect(TILE_W, SIDE_H, darken(base_color, 0.8))
ATOM = vstack(TOP, SIDE)
```

**Key properties:**
- Flat-lit (no baked shadows in atom itself)
- 4 materials: concrete, metal, stone, wood (extend via `MATERIALS` dict)
- Transparent areas: `RGBA8` format with alpha=0

### Workflow: Add New Voxel Material

1. Add entry to `MATERIALS` dict in `generate_voxel.py`
2. Run: `python3 tools/asset_generation/generate_voxel.py`
3. Switch to Godot window, wait 3–5 seconds for reimport
4. Run builder: `Godot --headless --path . --script godot/scripts/tools/build_voxel_tileset.gd`
5. Add `ATLAS_COORD_{MATERIAL}` constant in `godot/scripts/world/subcube_coords.gd`
6. **No texture_origin calibration needed** — analytically positioned

## Block TileSet Pipeline (Unchanged)

**Asset directory:**
```
ASSETS/ISOMETRIC/source_assets/generated/
├── floor_NE/NW/SE/SW.png       (256×128 floor diamond variants)
├── block_NE/NW/SE/SW.png       (solid tiles, 3 visible faces)
├── crate_*.png                 (props)
└── column_*.png                (props)
```

**Wall tile series REMOVED:**
- `wall_*`, `wallHalf_*`, `wallFace_*`, `wallCorner_*`, `wallCornerHalf_*` — **eliminated**
- Voxel system (`set_cell()` on `_voxel_layers`) replaces all wall rendering
- `EDGE_VISUAL_OFFSETS`, `CORNER_VISUAL_OFFSETS` calibration entries — **eliminated**

**Built by `build_tileset.gd`:**
- Scans `source_assets/generated/` for all non-wall PNGs
- Builds `tileset_blocks.tres` (256×128 tile_size)
- Contract unchanged; wall-specific calibration entries removed

### Workflow: Add New Block/Prop

1. Create generator (copy `generate_master_block.py` as template)
2. Run it → PNG to `source_assets/generated/`
3. Switch to Godot window, wait 3–5 seconds for reimport
4. Run builder: `Godot --headless --path . --script godot/scripts/tools/build_tileset.gd`
5. Tile becomes available in `tile_registry.gd` under its base name

## TileSet Builder Reference

| Builder script | Output | tile_size | When to run |
|---|---|---|---|
| `build_tileset.gd` | `tileset_blocks.tres` | 256×128 | After floor/block/prop PNG changes |
| `build_voxel_tileset.gd` | `tileset_voxels.tres` | 32×16 | After voxel PNG changes |

**Both builders:**
- Single-source scan (dedicated directory each)
- No merge, no fallback
- Clear error if PNG missing expected file

## Development Workflow (Asset + Godot)

**Step 1: Generate assets (terminal)**
```bash
cd /Volumes/Expansion/"----- PESSOAL -----"/PYTHON/INFILTRAITOR
python3 tools/asset_generation/generate_voxel.py
# or
python3 tools/asset_generation/generate_master_block.py
```

**Step 2: Let Godot reimport (GUI)**
- Switch to the Godot window (already open)
- Wait 3–5 seconds for asset relinking
- No manual rebuild needed; Godot handles import automatically

**Step 3: Run TileSet builder**
```bash
Godot --headless --path . --script godot/scripts/tools/build_voxel_tileset.gd
# or
Godot --headless --path . --script godot/scripts/tools/build_tileset.gd
```

**Step 4: Proceed with implementation**
- New tiles now available in the TileSets
- Use them in map definitions or procedural generation

## Guaranteed Asset Properties

**Voxel atoms:**
- Exact dimensions: 32×36 px (enforced by `generate_voxel.py`)
- Top face: isometric diamond inscribed in 32×16 bounding box
- Side face: flat-shaded rectangle 32×20, darkened 80%
- No baked directional shadow (runtime `BakeSystem` handles texture variation)
- Transparent areas: alpha=0

**Block tiles:**
- Canvas: 256×512 px for blocks (legacy); floor: 256×128 px
- Floor diamond: bW=(0,448), bE=(256,448), bN=(128,384), bS=(128,512)
- Geometry calculated, never hand-edited
